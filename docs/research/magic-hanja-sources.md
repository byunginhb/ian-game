# 한자 마법 배틀: 마법천자문·8급·7급 한자 출처 조사

- 조사일: 2026-08-16
- 적용 대상: `src/pages/MagicHanja.jsx`의 문제 한자 풀
- 결론: 급수 기준은 **사단법인 한국어문회 전국한자능력검정시험**으로 고정하고, **8급 50자 + 7급 신습 100자**를 기본 학습 풀로 쓰는 것이 가장 명확하다. 여기에 아울북 공식 자료에서 직접 확인된 『마법천자문』 1·2권 신규 한자 40자를 출처 태그와 함께 겹쳐 쓰고, 7급 범위 밖 8자는 별도 “마법천자문 주문” 보너스 풀로 두는 구성을 권장한다.

## 1. 기준과 출처

### 급수 한자

한국에는 한자 급수 시험 시행 기관이 여럿 있고 기관별 배정 한자가 완전히 같지는 않다. 이 문서는 현재 게임 데이터와 가장 잘 맞는 **한국어문회** 기준만 사용한다.

한국어문회 공식 [급수별 배정한자 페이지](https://www.hanja.re.kr/kccpt/exam/levelConfirm.do)는 다음을 명시한다.

- 8급 읽기 배정 한자는 50자다.
- 7급 읽기 배정 한자는 150자다.
- 상위 급수는 하위 급수 한자를 모두 포함한다.
- 같은 페이지에서 내려받는 공식 파일 `배정한자8급.hwp`와 `배정한자7급.hwp`에 각각 전체 문자가 수록돼 있다.
- 7급 파일은 “150자 = 8급 배정한자 50자 + 7급 신습한자 100자”라고 명시한다.
- 대표 훈·음은 같은 페이지의 `배정한자 전체 대표훈음 부수 음표 명기본(xls).xls`를 기준으로 확인할 수 있다.

따라서 게임 화면에서 “7급”을 8급과 중복 없이 보여 주려면 `7급 신습 100자`라고 명시해야 한다. 시험의 누적 범위를 뜻하는 “7급 전체”는 8급 50자를 합친 150자다.

### 마법천자문

출판사 북이십일/아울북의 공식 [(개정판) 마법천자문 1권 페이지](https://www.book21.com/book/book_view.html?bookSID=4869)는 권마다 신규 한자 20자를 선정하며, 특히 1~5권은 8~5급 중 사용 빈도가 높은 100자로 구성했다고 설명한다. 여기서 말하는 급수 표기는 한국어문회 기준이라고 페이지에 명시되어 있지 않으므로, **출판사 표기 급수와 한국어문회 급수를 같은 것으로 가정하지 않는다.**

공식 상세 이미지에서 직접 확인한 범위는 다음과 같다.

- [1권 공식 상세 이미지](https://www.book21.com/flv/book_info24/magichanja01.jpg): 신규 한자 20자와 본문 주문 예시 확인
- [2권 공식 상세 이미지](https://www.book21.com/flv/book_info24/magichanja02.jpg): 신규 한자 20자와 본문 주문 예시 확인
- 1권 공식 페이지는 이야기 소개에서도 보리도사가 바람 풍(風), 물 수(水) 마법 등을 쓴다고 명시한다.

## 3. 한국어문회 7급 신습 100자

아래는 공식 7급 누적 150자에서 8급 50자를 뺀 **7급에서 새로 배우는 100자**다.

```text
家 歌 間 江 車 工 空 口 旗 氣 記
男 內 農
答 道 冬 動 同 洞 登
來 力 老 里 林 立
每 面 名 命 問 文 物
方 百 夫 不
事 算 上 色 夕 姓 世 少 所 手 數 市 時 植 食 心
安 語 然 午 右 有 育 邑 入
子 字 自 場 全 前 電 正 祖 足 左 主 住 重 地 紙 直

下 夏 漢 海 花 話 活 孝 後 休
```

현재 게임의 `GRADE_7`은 95자이며, 공식 신습 100자 중 다음 5자가 빠져 있다.

| 누락 한자 | 한국어문회 대표 훈·음 | 게임용 간결 표기 |
|---|---|---|
| 旗 | 기 기 | 기 기 |
| 洞 | 골 동: / 밝을 통: | 골 동 |
| 夫 | 지아비 부 | 지아비 부 |
| 姓 | 성 성: | 성 성 |
| 子 | 아들 자 | 아들 자 |

콜론(`:`)은 공식 XLS의 장음 표시이며 게임용 간결 표기에서는 생략했다. 현재 목록에 공식 7급 신습 범위 밖의 문자는 없으므로 이 5자만 추가하면 정확히 100자가 된다.

## 4. 공식 자료로 확인된 마법천자문 한자

### 1권 신규 한자 20자

[공식 1권 페이지](https://www.book21.com/book/book_view.html?bookSID=4869)와 [공식 상세 이미지](https://www.book21.com/flv/book_info24/magichanja01.jpg)에서 확인했다.

```text
人 水 小 地 風 火 木 金 手 天 日 月 土 目 耳 門 兄 口 力 弟
```

상세 이미지의 본문 예시에서 실제 주문 장면으로 **火(불 화), 風(바람 풍), 水(물 수), 手(손 수)**가 직접 확인된다.

### 2권 신규 한자 20자

[공식 2권 페이지](https://www.book21.com/book/book_view.html?bookSID=4870)와 [공식 상세 이미지](https://www.book21.com/flv/book_info24/magichanja02.jpg)에서 확인했다.

```text
寸 活 九 足 角 靑 電 內 答 外 短 重 長 石 安 白 魚 數 貝 生
```

상세 이미지의 본문 예시에서 실제 주문 장면으로 **角(뿔 각), 魚(고기 어)**가 직접 확인된다.

### 1·2권과 한국어문회 8·7급의 교집합

1·2권 신규 한자 40자 가운데 32자는 한국어문회 8급 또는 7급에 포함된다.

```text
人 水 小 地 火 木 金 手 天 日 月 土 門 兄 口 力 弟
寸 活 九 足 靑 電 內 答 外 重 長 安 白 數 生
```

다음 8자는 1·2권 공식 신규 한자이지만 한국어문회 7급 누적 150자에는 없다.

```text
風 目 耳 角 短 石 魚 貝
```

게임에서는 이 8자를 급수 문제에 섞지 말고 `마법천자문 주문` 또는 `보너스 한자`로 분리하는 편이 정확하다.

## 5. 구현에 적합한 최종 구성안

### 기본 학습 풀

1. `8급`: 공식 50자
2. `7급 신습`: 공식 100자
3. 화면 표기는 `8급 50자`, `7급 신습 100자`처럼 중복 여부를 드러낸다.
4. 사용자가 “7급 전체”를 고르면 두 풀을 합쳐 150자로 출제한다.

### 마법천자문 연계 방식

각 한자에 출처를 나타내는 별도 메타데이터를 붙이는 방식을 권장한다.

```js
{
  char: '火',
  grade: 8,
  magicVolumes: [1],
  sourceTags: ['한국어문회', '마법천자문 공식 1권'],
}
```

- 처음 접하는 문제는 1·2권과 8·7급의 교집합 32자를 우선 출제한다.
- 8급 50자를 익힌 뒤 7급 신습 100자로 확장한다.
- `風·目·耳·角·短·石·魚·貝`는 급수 진도와 별개인 보너스 주문으로 제공한다.
- “마법천자문 등장” 표시는 공식 상세 이미지나 공식 권별 부제로 확인된 문자에만 붙인다.
- 작품의 대사·그림·캐릭터 자산을 그대로 복제하거나 공식 제휴 게임처럼 표시하지 않는다.

## 6. 데이터 정규화 주의사항

한국어문회 HWP에는 일부 한자가 호환 한자 코드로 들어 있다. 게임 데이터에서는 아래처럼 Unicode NFKC 정규화 결과인 통합 한자를 쓰는 것이 검색·중복 제거·저장에 유리하다.

| 공식 파일에서 보일 수 있는 글자 | 게임 저장값 |
|---|---|
| 金 | 金 |
| 車 | 車 |
| 不 | 不 |

글꼴에 따라 `靑/青`처럼 자형이 비슷하게 보이는 경우도 있으므로, 한국어문회 급수 데이터의 키는 `靑`으로 고정하고 화면 글꼴만 별도로 관리한다.

## 7. 확인 범위와 한계

- 한국어문회 8급·7급은 공식 HWP 원문과 전체 대표 훈·음 XLS를 내려받아 문자 수와 차집합을 대조했다.
- 마법천자문은 아울북 공식 웹 자료만 사용했다. 1·2권은 상세 이미지에서 신규 40자 전체를 확인했고, 1~20권은 공식 부제의 대표 한자를 확인했다.
- 3권 이후 각 권의 신규 20자 전체는 이번 조사에서 공식 자료로 전수 확인하지 않았으므로 목록에 넣지 않았다.
- “마법천자문에 나온 모든 한자”라고 부르지 말고, 현재 데이터는 “공식 자료에서 확인한 1·2권 신규 한자 및 1~20권 대표 한자”라고 표현해야 한다.
