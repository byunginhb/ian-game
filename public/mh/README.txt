한자 마법 배틀 - 캐릭터 이미지 넣는 법
=======================================

게임은 sprites 폴더의 WebP 스프라이트를 먼저 사용합니다.
스프라이트가 없으면 이 폴더의 투명 PNG를 확인하고, 둘 다 없으면
게임이 직접 그린 캔버스 캐릭터로 자동 대체됩니다.

현재 sprites 폴더에는 게임용 2.5D 캐릭터 스프라이트가 들어 있습니다.

직접 교체하려면 아래 key 그대로 저장하세요.
우선순위: sprites/<key>.webp → <key>.png

[주인공]
  sonogong.png        손오공

[악당 — 3관문마다 혼세마왕]
  honse.png           혼세마왕  (3, 6, 9... 관문 보스)
  heuksim.png         흑심마왕
  jiltu.png           질투마녀
  tarak.png           타락마왕
  tamyok.png          탐욕마왕
  bunno.png           분노군단장
  nate.png            나태군단장
  gyoman.png          교만지왕
  janhok.png          잔혹마왕
  bulmyeol.png        불멸대왕
  oman.png            오만군단장
  amheungnoya.png     암흑노야
  heukryong.png       흑룡
  daemawang.png       대마왕
  geomeun.png         검은마왕
  amheuksangje.png    암흑상제

권장 크기: 세로 200~400px 정도, 정면 전신, 배경 투명.
이미지를 넣은 뒤 브라우저 새로고침하면 적용됩니다.

※ 저작권 안내: 이미지는 직접 준비해 이 폴더에 넣어 주세요.
   (개인 학습용으로만 사용)
