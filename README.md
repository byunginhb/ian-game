# IAN Games

이안과 함께 아이디어를 만들고 즐기는 22가지 게임 놀이터입니다. 게임의 규칙과 캐릭터를 유지하면서 PC 키보드·마우스와 모바일 터치를 지원합니다.

## 실행

React 19, Vite 7, JavaScript/JSX, pnpm을 사용합니다.

```sh
pnpm install
pnpm dev
```

```sh
pnpm lint          # ESLint
pnpm test          # 게임 시계·화면 배율·영토 전투 단위 테스트
pnpm build         # 프로덕션 빌드
pnpm preview       # 빌드 미리보기
```

## 브라우저 검증

최초 한 번 테스트용 브라우저를 설치합니다.

```sh
pnpm exec playwright install chromium webkit
pnpm test:e2e
```

PC Chromium, Android 크기 Chromium, iPhone 크기 WebKit, 320px 작은 화면, 모바일 가로 화면에서 전체 게임의 시작·입력·일시정지·복귀를 검증합니다. 2048 병합, 테트리스 줄 삭제 중 중복 입력, 스택 타워 마우스 배치, 배경 전환 시 시간 보존, 저장소 접근 차단도 검증합니다. 브라우저 에뮬레이션이므로 실제 기기의 GPU 성능·OS 제스처까지 재현하지는 않습니다.

## 공통 게임 동작

- `src/lib/gameClock.js`: 게임 시간, 프레임, 반복 작업, 지연 작업의 공통 시계입니다. `GameSession`이 창 이탈·화면 숨김·‘잠깐 쉬기’에서 시계를 정지하고, 게임을 나갈 때 남은 작업을 취소합니다. 계속하기를 눌러야 재개됩니다.
- 새 게임 로직에서는 기본 `setTimeout`, `setInterval`, `requestAnimationFrame`, `Date.now`, `performance.now` 대신 `gameClock`의 같은 이름 메서드와 `now()`를 사용합니다. 오디오 합성에는 AudioContext 자체 시계를 사용합니다.
- 기존 물리 계산의 고정 간격은 유지하며, 화면 갱신은 하나의 `requestAnimationFrame`으로 처리합니다. 지연 프레임은 최대 50ms까지만 따라잡고, 반복 콜백은 프레임당 최대 5회 처리합니다.
- `useGameScale`은 주소 표시줄 변화와 화면 회전에 반응합니다. 좁고 낮은 화면에서는 게임을 읽을 수 있는 크기를 유지하고 페이지 세로 스크롤을 허용합니다. 터치 제스처 차단은 조작 영역으로 제한합니다.
- 물리 시뮬레이션은 ref에서 계산하고, React에 넘기는 화면 상태는 복제하여 게시합니다. 상태 updater 안에서 점수·타이머·다른 상태를 변경하는 부수 효과를 만들지 않습니다.
- 게임 목록은 `src/data/games.js`, 각 게임의 지연 로딩은 `src/App.jsx`에서 관리합니다. 게임을 추가할 때 두 곳에 등록합니다.
- 마우스·트랙패드·터치로 게임 버튼을 클릭하면 공통 게임 영역으로 포커스를 돌려주어 방향키·스페이스 조작을 바로 이어갑니다. Tab/Enter로 버튼을 조작할 때는 포커스를 유지하며, 입력창·선택창·대화상자는 이 처리에서 제외합니다.
- 운영 서버는 `/game/*` 직접 접근 시 `index.html`로 연결하는 SPA fallback이 필요합니다.

## 이안이의 보물찾기 잘하자

`/game/treasure-kingdom`에서 플레이합니다. 초등학교 4~5학년을 대상으로 왕국 붕괴의 원인을 추적하는 2.5D 탐험 어드벤처입니다. 정글 → 바다와 섬 → 우주 관측소 → 거대한 정원을 탐사하며 세계마다 보물 25개와 수호자 3명을 만납니다. 보물 100개를 왕국으로 가져오면 구역이 단계적으로 복원되고, 구역마다 5·12·25개를 확보하면 이야기의 기록이 해독됩니다.

- 방향키/WASD 또는 화면 터치·마우스·트랙패드 목적지 지정으로 이동합니다. 길게 누르기·드래그는 연속 이동입니다. Space는 점프, Shift는 회피, E는 탐지·장치·현장 조사·대화이며 전투 중 Space는 자동 조준 미사일과 충전 필살기로 바뀝니다. 맵 안의 물·나무·바위·유적을 막힘없이 통과하며, 목적지까지 바로 이동합니다.
- 매몰된 보물은 탐지로 찾고, 장치는 회로·신호 기억·출력 조합·경로 연결로 복구합니다. 임무는 원거리 순차 조사·기록 해독, 중계기 신호 동기화, 대원 구출·호위로 구분됩니다. 장치의 해법도 세계마다 달라집니다. 길 밖의 물도 자유롭게 건널 수 있으며 늪·불·전기 등의 위험 지역은 피해를 줍니다. 봉인은 보물 10·20·22개에서 열리고 최종 수호자가 마지막 보물 세 개를 줍니다. 수호자는 방사파·돌진·교차 공격·부채꼴·뿌리·구체 패턴을 사용하고 체력이 줄면 빨라집니다. 탐사 체력이 소진되면 캠프로 복귀하며 보물은 잃지 않습니다.
- PC는 탐험 시작 버튼에서 브라우저 전체화면으로 진입합니다. Esc 또는 화면 복귀 버튼으로 종료하며, 전체화면이 허용되지 않아도 장면은 브라우저 뷰포트를 채웁니다. 모바일도 화면 전체에 지도와 터치 조작을 배치합니다.
- 보물·임무 수락·조각·탐지 결과는 즉시, 위치는 2초마다 또는 화면 이탈·탐험 종료 때 저장합니다. 주 저장본과 백업을 검증하며 기존 버전의 보물 진행도 유지합니다. 저장 실패 안내와 재시도 버튼이 있습니다. 같은 기기·브라우저·사이트 주소에서 이어집니다.
- Phaser 3.90, 새로 제작한 환경·캐릭터·수호자 아트, 깊이 정렬·접지 그림자·랜턴 조명·점프·탐지·불꽃·파도·번개 공격 연출을 사용합니다. 게임 장면과 아트는 탐험 시작 때 지연 로딩합니다. 외부 폰트 요청은 없습니다.
- NPC 미션의 계산·추리는 초등 2~3학년 수준을 목표로 덧셈·뺄셈·작은 수 곱셈·수의 규칙 찾기로 조정했습니다. 4×4·5×5 노노그램과 1~3을 채우는 3×3 미니 스도쿠도 현장 임무에 등장하며, 한 칸 도움과 초기화를 지원합니다. 기존 회로·신호·출력·길찾기 장치는 유지합니다.
- 보물 100개를 왕국에 전달하면 완주 날짜·실제 플레이 시간·최고 기록을 저장합니다. 일시정지·로딩·화면 이탈은 제외하고 임무 풀이 시간은 포함합니다. 완주 후 기록을 보관한 채 처음부터 다시 도전할 수 있습니다. 이전 버전의 완주는 시간 미측정으로 유지합니다.
- 캐릭터는 앞·뒤·옆 12개 보행 포즈를 실제 이동 거리에 맞춰 재생하며, 발걸음마다 발자국·먼지·조용한 발소리가 나옵니다.
- [설계·저장·검증·실제 화면](docs/treasure-kingdom.md), [아트 파일과 제작 프롬프트](src/assets/treasure/README.md)

```sh
pnpm exec playwright test tests/treasure-kingdom.spec.js tests/game-focus.spec.js
```

## 내가 다 먹었다!

`/game/conquest`에 들어오면 먼저 아이·어른 모드를 고른 뒤, 여섯 진영 중 하나로 1~20탄을 순서대로 정복합니다. 팀 선택 화면의 ‘모드 바꾸기’로 다시 선택할 수 있습니다. 모든 탄에 여섯 팀이 참가하며, 땅은 12개에서 36개까지 늘고 적의 생산·출정 속도도 높아집니다. 지도마다 불규칙한 해안선, 국경이 맞닿은 대륙, 떨어진 섬과 넓은 바닷길이 섞입니다.

- **아이 모드**는 기존 초기 병력·생산 속도·AI·준비 시간을 그대로 유지합니다.
- **어른 모드**는 초기 병력 우위를 줄이고 적의 생산·판단 속도를 높입니다. 상대는 이동 중 늘어날 수비 병력을 예상하고, 공격받는 본진을 지키며 위험한 아군 땅에 지원군을 보냅니다. 후반에는 여러 땅에서 동시에 출정합니다. 다섯 명씩 전원 출정, 충돌 상쇄와 진영 특성은 두 모드에서 같습니다.
- 어른 모드의 첫 5탄은 준비 시간과 시작 병력을 조금 더 주어 적응하도록 했습니다. 1탄은 내 병력 48명·적 진영당 28명으로 시작하고, 적의 준비 시간은 약 3.9초입니다. 초반 보정은 6탄까지 서서히 줄어들며, 전체 어른 모드의 적 판단 간격도 이전보다 조금 여유로워졌습니다.

- 내 땅에서 다른 땅으로 드래그하거나, 출발지와 도착지를 차례로 누르면 출정합니다. 바다에 놓으면 취소됩니다. 키보드는 Tab + Enter로 조작합니다.
- 출정하면 현재 병력 전원을 보내며, 0.32초마다 최대 5명씩 차례로 출발합니다. 캐릭터 하나가 군사 한 명이고 이동 중 숫자는 표시하지 않습니다. 이동 중 다른 진영의 군사를 만나면 한 명씩 서로 상쇄되고, 살아남은 군사만 도착해 전투·지원에 반영됩니다. 같은 진영끼리는 그대로 지나갑니다. 각 땅은 최대 150명까지 생산합니다.
- 닌자고는 생산·이동이 균형 잡혔고, 소닉은 이동, 마리오는 생산, 대마왕은 공격, 손오공은 이동·공격, 아이언맨은 방어에 강합니다.
- 빈 땅을 포함한 모든 땅을 점령하고 적의 남은 군사도 막으면 승리합니다. 마지막 땅을 잃어도 이동 중인 아군이 있으면 재점령을 시도할 수 있습니다.
- 모드·팀별 클리어와 최고 별점을 따로 저장합니다. 기존 `ian-conquest-v1` 기록은 아이 모드에 그대로 남으며, 어른 모드는 `ian-conquest-adult-v1`에 별도로 저장합니다. 한 모드의 클리어로 다른 모드의 탄이 열리지 않습니다. 저장소가 차단되어도 현재 세션에서 진행할 수 있습니다.
- 팀 선택·출정·군사 충돌·점령·영토 상실·승패에 효과음이 나고, 전투 중에는 오리지널 모험 배경음이 흐릅니다. 첫 조작부터 소리가 켜지며 상단 소리 버튼으로 함께 끌 수 있습니다. 음소거는 `ian-conquest-sound-v1`에 저장합니다. 도움말·일시정지·창 이탈 시 음악도 멈추고, 게임을 나가면 오디오를 정리합니다. Web Audio로 합성하므로 음원 다운로드가 필요 없고, 반복 충돌의 재생 간격·동시 발음 수·전체 음량을 제한합니다.
- 로이드·소닉·대마왕·손오공은 정교한 3D 일러스트로 생성했고, 마리오·아이언맨은 공식 캐릭터 아트를 사용합니다. `src/assets/conquest/`의 투명 PNG를 선택 카드·대장·이동 군사에 함께 사용합니다. 생성 프롬프트는 해당 폴더의 `README.md`에 기록했습니다. 외부 이미지·폰트 요청이나 추가 패키지 없이 실행됩니다.
- `src/lib/conquest.js`는 지도 생성·병력·AI·저장 데이터 로직, `src/pages/Conquest.jsx`는 화면·입력·게임 시계 연결을 담당합니다.
- `src/lib/conquestAudio.js`는 배경음·효과음 합성과 전투 이벤트 판별, `src/hooks/useConquestAudio.js`는 사용자 입력·일시정지·음소거 연결을 담당합니다.

```sh
pnpm exec playwright test tests/conquest.spec.js tests/conquest-difficulty.spec.js tests/conquest-audio.spec.js
```
